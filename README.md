# Online Retail Customer Segmentation

Online Retail Customer Segmentation using K-Means and Hierarchical Clustering

## Overview

This project analyzes customer purchasing patterns in an Online Retail
dataset using unsupervised learning techniques. The main objective is to
identify groups of customers with similar purchasing behaviour through
clustering.

## Clustering Techniques

- K-Means Clustering
- Hierarchical Clustering

## Dataset

The project uses the **Online Retail Dataset**, which contains
transaction-level information such as:

- Invoice Number
- Stock Code
- Product Description
- Quantity
- Invoice Date
- Unit Price
- Customer ID
- Country

## Methodology

The project follows these major steps:

1. Explore and understand the dataset
2. Clean the transactional data
3. Handle missing values
4. Perform RFM analysis
5. Prepare the data for clustering
6. Scale the required features
7. Apply K-Means clustering
8. Use the Elbow Method to determine a suitable number of clusters
9. Apply Hierarchical Clustering
10. Visualize the hierarchical clusters using dendrograms
11. Analyze the resulting customer segments

## RFM Analysis

Customer purchasing behaviour is represented using three RFM measures:

- **Recency** – how recently a customer made a purchase
- **Frequency** – how often a customer made transactions
- **Monetary** – the total amount spent by a customer

These features are used for customer segmentation through clustering
algorithms.
